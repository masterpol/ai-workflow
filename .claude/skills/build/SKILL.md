# Build

> **Recommended capability profile:** `standard` — default coding workhorse. Select an available model using `ai-framework/integrations/harnesses.md`.

Phase 2 of the new pipeline. See `ai-framework/workflow/phases/2-build.md` for full activities.

## When to use

- After `/plan` — work through scopes in the order and parallelism specified in `plan.md`
- Bug-fix: enter directly (single implicit scope; mandatory `log.md` entry)
- Hotfix: enter directly (audit deferred; rollback plan required at /ship)

## Activities

1. **Load context** — read `plan.md`, `hill.md`, and target files. Read `ai-framework/rules/coding-standards.md` + `boundaries.md` **and** the matching `.project/rules/*.md` companion(s) for the scope's stack area (`frontend-framework.md`, `styling.md`, `backend.md`, `mobile.md`, `ai-structured-output.md` — whichever exist; generated by `/setup` from this project's actual conventions, not hypothetical ones). The generic rule states the principle; the companion states this project's concrete convention for it — both apply, and the companion wins on anything project-specific it says explicitly.
2. **Execute scopes** — implement each scope following plan. Parallel-dispatch marked scopes as subagents, each at the model `plan.md` recorded for it (not `/build`'s own `standard` profile), only where the active harness supports nested dispatch — otherwise run that scope as a sequential pass instead.
3. **Verification before done** — every scope: run its machine-checkable exit criterion before marking done. No assertions without evidence.
4. **Update hill chart** — `/hill {scope} {position}` after each scope. Stuck-uphill detector: same position × 3 = "rabbit hole?" warning.
5. **Log deviations** — any plan ↔ reality drift goes to `deviations.md` immediately.
6. **Log incidents** — build errors, unexpected findings → `log.md`.

## Adaptive gate

| Appetite | Per-scope gate | Build-start gate |
|----------|---------------|-----------------|
| small-batch | auto-advance | auto |
| big-batch | gated (evidence required) | gated |
| bug-fix | auto | gated |
| hotfix | auto | gated + rollback plan |

## Output

- All scopes at `done` on `hill.md`
- `deviations.md` updated
- `log.md` updated
- Hill-chart roll-up + evidence presented for approval → `/audit`

## Confirmation gate

Present hill-chart roll-up + evidence + open deviations. Options: **Approve → /audit** / Revise specific scope / Back to /plan / Stop.

## Transition

→ `/audit`
