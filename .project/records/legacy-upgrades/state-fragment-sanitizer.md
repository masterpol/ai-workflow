## What shipped

The sanitizer is a library: untrusted fragment text in, either re-emitted allow-listed markup with its citations or a rejection with a closed reason out. It reads no files, injects nothing and writes no report. Scopes S1 to S8 are complete.

- S1 (2026-10-19, inline): security spike with caps table, ten decisions D1 to D10, a 52-row mutation list, line budgets and a parser prototype timing.
- S2: strict XML-subset parser, iterative, capped, linear; Orca worker (Claude deep).
- S3: allow-list validator, content model, canonical re-emit, byte-idempotence; implemented by the coordinator after the owner chose `orca=normal`.
- S4: evidence-path and number checker reusing the shared `safeEvidencePath`; Orca worker (Claude standard).
- S5: mutation matrix, positive controls, named reasons, timed fuzz (Claude standard).
- S6: bounded rejection formatter whose messages never echo fragment content (Claude fast).
- S7: golden-dataset mapping, 13 owned cases enforced and 9 deferred to `state-ai-authoring` (Claude standard).
- S8: documentation and version log, 2.35.0 (Claude fast).
- Audit: three cycles, final cycle clean, 531 tests, 666 of 800 production lines.

Budget: 12 files against a cap of 15 (3 production modules, 4 test files, the spike record, the committed dataset, `state-report.md`, `VERSION`, `CHANGELOG.md`); the pitch had projected about 6 files and 1,000 lines because it did not count docs, version log, spike, per-module tests or the mapping test. ## Scope and contract

Problem: the owner wanted AI-written HTML and SVG (diagrams, analysis) in the report and chose raw markup over a structured spec; AI output is untrusted, so nothing could enter an inert page until a sanitizer provably refused everything dangerous. Owner decision 2026-10-19: the AI writes SVG or HTML directly, the script sanitizes and injects; the hand-written allow-list counts as the "DOMPurify or equivalent" that `rules/security.md` section 4 asks for, so no runtime dependency was added. Pitch split from the first draft `state-ai-fragments` after critique B2; the pitch was bet "bet all three shaped pitches, plan in order" with open action A5, committing the untracked dataset. The dataset was already tracked by S7, satisfying A5 without a new commit.

Public API fixed by S1 (pure): `parseFragment(text, limits?)`, `sanitizeFragment(text, options?)` returning `{ ok, html, citations }` or a rejection, `rejectionMessage(r)`, and `checkCitations(citations, snapshot, root, deps?)`. A rejection is `{ ok: false, reason, count, token }` where token is a validated name or null, never a value. Class, token and marker lists are injected; defaults are the seven color tokens, no page classes and the marker class `marker-arrow`. `status` and `status-*` are always refused so a fragment cannot imitate the observed-fact style.

Reused, not copied: `safeEvidencePath` through `createStateRender(deps)`, `isSecretName`, `facts(snapshot)`, `printable`, `readData` for the dataset, `tempFixture` for fixtures; the mutant convention `X_UNDER_TEST` environment imports. No shared state module was edited (state-render, state-snapshot, state-structure, state-theme, state-pages; checked against base `d2d8ee1d0b71a6450464f2359ba9fd47bce54424`). setup-validator and bundle-sync already pick up new scripts; the doctor syntax-check list was already partial and was left unchanged.

Resolved at shape time: allow-list over deny-list (every critique attack class became a mutation case); parse differential handled by no HTML error recovery, reject, re-emit from the tree and an idempotence test; rejection messages carry only class, count and a capped validated token; reject the whole fragment, keep earlier findings, never repair. Pushed to plan with owners: parser size (upper estimate 800+ lines, owner S1), token and marker set from `state-report-redesign` (owner S2), whether to cite the critique's browser behavior list or hand-check (owner S1). Pushed to no-go: authoring, injection, provenance label and staleness (`state-ai-authoring`); HTML5-tolerant parsing, scripts, interactive diagrams, Mermaid. Resolved during build: sparse citation arrays, Node strip-only syntax, two Orca launch failures from an interactive shell prompt, and the caller-limits Proxy bypass of the hard depth cap. Plan risks R1 to R16 included: no persisted browser behavior list (rebuilt in D5), shared check has no transcript rule and returns only a boolean (shape pre-classification, shared check stays final authority), no number-to-fact binding (D6), macOS tmpdir realpath alias, quadratic regex, the dataset staying JSON until the TOON reader is proven, 4 of 17 deterministic cases being injector tests (closed deferred list with exact-partition assertion), TAP being Node-specific (mapping test always spawns Node and never skips), a possible `state-render` import cycle once the injector lands, and cross-pitch contention on `VERSION` and `CHANGELOG.md`.

## Standing constraints

- No script, event handler, external reference or `url()` passes: element and attribute allow-lists, `on*`, `style`, `id`, scheme and content-model rules each refuse with a named reason and a killed mutant.
- The model's claim of safety is never trusted: the sanitizer re-parses and re-emits from the tree, and canonical output is parsed against the same caps after escaping.
- Nothing is written anywhere; the library returns a result and never touches a report file.
- No runtime dependency without an explicit owner decision.
- Fragment content never reaches error text: only a closed reason, a bounded count and a validated name or `(other)`.
- The pitch's 800-plus-line parser estimate did not hold (shipped 266 lines), so the `/shape-lite` trigger never fired. Trim the allow-list rather than raise a cap.

## Design decisions

Caps (S1; the live guide has a caps table, [state-report.md](../../../ai-framework/integrations/state-report.md#defaults-and-caps)): 65,536 UTF-8 bytes, depth 20, 2,000 nodes, 12 attributes per element, 512 attribute value (8,192 for `d`), 4,000 per text node, 32 for names, 50 citations, fuzz bound 1,000 ms per vector. Line budgets: parser 350, validator 300, evidence 150, total 800; never raised.

Decisions D1 to D10 (condensed):
- D1 parser: single forward cursor with an explicit stack, no recursion, no regex over unbounded input, byte cap before scanning, per-call state; malformed UTF-16, raw `<` in attributes and missing separators reject; caps are positive safe integers and bad options return `invalid-options`; raised caps are trusted test controls only.
- D2 entities and text: only `&amp; &lt; &gt; &quot; &apos;` decode, everything else is `character-reference`; emit escapes all five (`&apos;` not `&#39;`); reject C0 except TAB/LF/CR, C1 including DEL, bidi overrides U+202A to 202E and isolates U+2066 to 2069; names must be canonical case; duplicate attributes detected case-insensitively.
- D3 allow-list: HTML `h2 h3 h4 p ul ol li table caption thead tbody tr th td code pre strong em span a data`; SVG `svg g rect circle ellipse line polyline polygon path text tspan title desc`; no `xmlns`; `on*`, `style`, `id` and `url()` refused before per-element validation; `javascript:` refused after removing ASCII whitespace; geometry finite and at most 1e6, `d` limited to M L H V C S Q T A Z with arity and arc flags checked, transforms limited to translate, scale and rotate.
- D4 content model: closes the HTML parser differentials; no HTML inside svg, text only in `title` and `desc`, no block through span or anchor, no nested anchors or headings, lists, tables (`caption? thead? tbody`, exactly one tbody) and SVG text structure enforced, no void or self-closed HTML. Self-closed SVG expands on emission.
- D5 browser evidence: deterministic fixtures only (WHATWG foreign-content and in-table modes read 2026-10-19); no browser smoke, no new dependency; injection only in an ordinary HTML flow container.
- D6 numbers: bound through `<data value="path">N</data>`; own-property path lookup, arrays allow only `length` or bounded indices, `__proto__`, `constructor`, `prototype` refused; equality numeric after strict decimal parsing; a bare ASCII numeral outside `code`, `pre` and `data` counts as unbound and `checkCitations` rejects it as `unbound-number`. The ASCII-digit scope is deliberate; worded and other-script numbers belong to authoring.
- D7 colors, classes, markers: `fill` and `stroke` accept exactly `var(--TOKEN)` for a trusted token or `none`; emitted from the parsed token; marker classes start `marker-` and must be in the marker list; marker elements, ids and URLs stay refused; the host owns CSS marker definitions; browser appearance under CSP is unverified.
- D8 evidence paths: classify shape first for named reasons, then require snapshot membership and the shared `safeEvidencePath` after canonicalizing the root once; transcript policy refuses `transcripts`, `sessions`, `.sessions`, `session-logs`, `conversation-logs` directory segments, transcript, conversation and session-log basenames and `.jsonl` files.
- D9 hrefs: canonical hrefs are project-relative; the injector owns the `../../` prefix; a successful sanitize result alone is never permission to inject.
- D10 types and failures: parser owns `reject(reason, count, token)` with count clamped to 1..999999; rejection messages use `printable` then a closed grammar; the `printable` mutant may be redundant and must be measured, not weakened.

The 50 reason classes are listed in [state-report.md](../../../ai-framework/integrations/state-report.md#reason-classes) (the spike lists 50). Count means occurrences known at first failure; the first deterministic reason wins, never strip-and-continue.

Theme drift: the plan compared `Object.keys(FALLBACK.light)`, but that includes `radius`, `fontSans`, `fontMono`; S3 compares only the seven color-valued keys, no shared module change. S3 also parses canonical output against the same limits after escaping and decimal expansion, so an accepted fragment stays byte-idempotent and one whose canonical form exceeds a cap rejects with that cap's reason. Review refinements inside S3: SVG shapes reject whitespace children, structural HTML text permits only ASCII whitespace (so NBSP cannot trigger foster parenting), class normalization splits only ASCII whitespace.

Rejection message contract (S6): `fragment rejected: <reason> (<count>)` with optional ` at <name>` or ` at (other)`, at most 120 characters, no part of any canary, malformed runtime objects get a safe generic message without getter or coercion calls. A first worker patch stored `(other)` in metadata; it was restored so the formatter displays null as `(other)` and the token contract holds.

Dataset mapping (S7): 22 unique case ids, exact disjoint partition. Owned and enforced (13): `reject-script-element`, `reject-event-handler`, `reject-smil-href`, `reject-external-use`, `reject-style-attribute`, `reject-entity-encoded-javascript`, `reject-structural-constructs`, `reject-external-anchor`, `evidence-path-not-in-snapshot`, `number-mismatch`, `reject-oversize-and-deep`, `accept-valid-fragment`, `rejection-message-does-not-echo`. Deferred to `state-ai-authoring` (9): live-only `database-deployment-claim`, `uncited-claim`, `tokens-slot-invented-totals`, `prompt-injection-in-evidence`, `sparse-snapshot`; injector cases `failure-isolation`, `stale-fragment-default-and-strict`, `reuse-only-when-hash-unchanged`, `ai-label-always-present-and-unspoofable` (its sanitizer half is tested here). Each owned id needs a column-zero `ok` line with the exact `[id]` prefix and no SKIP or TODO; the child must exit 0 with a complete summary of zero fail, cancelled, skipped, todo; synthetic negative controls cover skipped, todo, failed, absent, similar-name, nested, stdout, escaped-name, malformed-summary and invalid-partition. The mapping test spawns the three fragment suites (270 child tests) with bounded timeout and no shell.

Mutation ledger (S1, 52 rows, each with an exact before-string, a named test and an expected reason): M1 to M21 parser (caps, DOCTYPE, ENTITY, CDATA, comment, PI, namespace, entity set, unclosed, mismatch, duplicate attribute, quoting, control characters, well-formed Unicode); M22 to M34 validator and emitter (element, `on*`, style, id, `url()`, script scheme, attribute, class, color token, marker, content model, escaping, canonical numbers); M35 to M49 evidence (snapshot membership, shared authority, traversal, absolute, scheme, percent, backslash, secret, transcript, citation cap, unknown fact, prototype guard, numeric leaf, numeric equality, unbound digits); M50 token provenance; M51 `printable` defense; M52 TAP skip directives. A kill needs a same-layout unmodified baseline that exits 0 and a mutant that exits 1 with the named assertion; fixture, import or type failures never count.
