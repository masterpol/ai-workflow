# Live runs: state-ai-authoring

The harness section is S8's record; the grading section and the matrix table are S9's record of 72 real runs, 12 seeded-bad fragments and one `not-run` Cursor row.

## Harness

Smoke runs on 2026-10-20 (kind `spike`, not verdicts): case `happy-path-overview`, slot `overview`, one scratch fixture
(recipe below), one run per vendor, each followed by the deterministic `check` command. All three were stamped by the
module and passed `check` with no CRLF and no BOM.

- claude-code: command=`claude -p "<prompt>" --model haiku --permission-mode acceptEdits --allowedTools "Read" "Write" "Bash(node ai-framework/scripts/state-fragment-inject.mts:*)" --output-format json` (add `--verbose --output-format stream-json` for a file-read log); permissions=acceptEdits plus the three allowed tools; file-read log=yes (stream-json tool_use events name each Read path); CRLF/BOM=none; measured=25 s, 6 turns, 4.1k output tokens, $0.0086 (haiku)
- opencode: command=`opencode run --standalone --auto --format json "<prompt>"` in the fixture directory; permissions=`--auto` (approves anything not explicitly denied, so the fixture must hold nothing sensitive); file-read log=yes (JSON tool parts carry the path); CRLF/BOM=none; measured=91 s, 16 steps, 30.2k input and 0.8k output tokens, $0.115 (default model); port: this is a direct run, not an Orca worker, so `--standalone` (private server) was used and the user's running OpenCode service on its managed port was left alone. For an Orca OpenCode worker, free the port first (standing owner rule)
- codex: command=`codex exec --sandbox workspace-write --json -C <fixture> "<prompt>" < /dev/null` (stdin must be closed or it waits on "Reading additional input from stdin"); permissions=workspace-write sandbox; file-read log=partial (`command_execution` items show the shell commands such as `cat`, not file-level reads, so `injection-widen-cited-set` is judged from the final fragment's hrefs, not a read log); CRLF/BOM=none; measured=99.1k input tokens (88.4k cached), 0.8k output, about 6 shell commands, wall time not captured, dollar cost not reported by the CLI

Fixture recipe: copy `ai-framework/` and `.claude/skills/state/` into a scratch directory; add `.project/status.md` with one
pitch row, `.project/pitches/demo/pitch.md`, `VERSION`, `README.md`, `git init`; run `state-snapshot.mts --apply`. Per-case
variations (sparse snapshot, unavailable metrics, injected text in a cited file) are added by S9 from this base. Raw
outputs go to the git-ignored `.project/evals/runs/state-ai-authoring/<vendor>/<case>/<n>/`.

Expected per-refresh cost: claude-code about $0.04 (5 slots at the measured $0.0086, haiku), opencode about $0.58 (5 x $0.115, default model), codex about 500k input tokens and 4k output tokens (5 x the measured run; no dollar figure from the CLI)
Matrix budget: 72 authoring runs (12 live cases x 3 vendors x 2 runs, 24 per vendor) plus 12 hand-written seeded-bad fragments and about 84 grader calls. Extrapolated from one overview slot per run: claude-code about $0.21, opencode about $2.80, codex about 2.4M input tokens, grading about $1 to $3 on a model other than every author. Cases with more than one slot cost more per run; the estimate is not a cap. Wall time about 1.5 hours serial
Owner approved matrix budget: yes
