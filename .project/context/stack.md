# Stack Context

## Stated Direction

The intended application direction is:

- TypeScript.
- TanStack Start and only the TanStack packages justified by the approved product scope.
- Tailwind for styling.
- Vite as required by the selected application setup.
- Ox tooling as needed; the exact Ox tools and configuration are not selected.

## Not Yet Installed Or Decided

No `package.json`, package manager, dependencies, scripts, formatting, linting, testing, database, authentication, CMS, cloud provider, hosting, or CI/CD configuration has been created.

This project phase must not turn the direction above into an implementation decision. The technical foundation will be proposed after discovery confirms content volume, access-control needs, operations, budget, and infrastructure constraints.
