# Conflicts and doubts

- The group pattern addresses bulk that can be judged together. The individual-file pattern addresses decisions, approvals and other files whose loss must be judged separately. A count and tree hash validate the group’s membership and content. They cannot supply individual judgment. At the entry cap, split the pitch if its files still need individual entries.
- The staging incident’s historical 200-file ceiling covered files outside covered sections. The later 2,000-file bound covers total files. The sources give no separate current numeric entry cap for files requiring individual judgment.
- The count prefix removed from the tree hash was redundant. Mutation checks still caught ignoring the separate member count.
- The cause of the final-verification child failure is unconfirmed. Later successful runs leave it open. The scratch text gives the raw SHA-256 and reports a match for the original normalized hash without supplying that digest.
