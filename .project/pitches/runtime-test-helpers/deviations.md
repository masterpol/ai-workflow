# Deviations: runtime-test-helpers

- S1: `FsDeps` did not expose `symlinkSync`. Added `symlinkSync(target, link)` to `runtime/types.mts` and `runtime/node.mts` (bun inherits from node). The guard in `runtime/invariants.test.mts` still passes (adapter set unchanged).
- S1 (audit cycle 1): `tempFixture` gained `{ resolve?: boolean }` (default true) so callers can get the un-resolved `mkdtempSync` path. The escape guard refuses keys whose `path.resolve` leaves the temp root.
- S1 (audit cycle 1): `memoryFs` `links` changed from `string[]` (dangling-only) to `Record<linkPath, targetPath>` (empty target = dangling). `statSync` now follows a valid link to its target; `lstatSync` reports the link. Breaking change to the helper API; `docs-links.test.mts` updated.
- S1 (audit cycle 1): `captureIo` pins `isTTY: false` on both streams.
- S1 (audit cycle 1): `runScript` reads `AI_WORKFLOW_RUNNER` from `deps.proc.env` and uses the bun exec path when set, otherwise falls back to the current runtime.
- S2: `tempFixture` callers in the refactored tests must `deps.fs.rmSync(root, { recursive: true, force: true })` themselves; the helper does not register a `t.after()` cleanup. `orca-apply.test.mts` keeps its existing `t.after(rmSync)` pattern in `tmp()`.
- S4: Binary file reads in `orca-apply.test.mts` use `Buffer.from(deps.fs.readBytesSync(...))` because `deps.fs.readBytesSync` returns a `Uint8Array` and the test compares against a `Buffer`. `deepEqual` treats `Uint8Array` and `Buffer` as different.
- Parallel dispatch: the plan flagged S2-S4 as parallel subagents; the build ran them sequentially because the harness's nested-dispatch support is unverified and the refactors are mechanical. No impact on outcome.
- Acknowledged (audit cycle 1): `runScript` `NODE_FLAGS` branch is dead on Node ≥22.18 and Bun (the local env is v24.21.0 and 1.4.2). It exists for Node 22.12–22.17 per `AGENTS.md`; a CI matrix on 22.14 would prove it. Deferred to /cooldown.
- Acknowledged (audit cycle 1): `readdirEntriesSync`, `readBytesSync`, `Uint8Array` and empty-fixtures branches of `memoryFs` are not unit-tested. No current pilot needs them. Deferred until a pilot does.
- Acknowledged (audit cycle 1): `CapturedDeps` widens the deps object handed to production code with `out`/`err` fields. Harmless today (no test serializes or logs the object). Logged for /cooldown.
