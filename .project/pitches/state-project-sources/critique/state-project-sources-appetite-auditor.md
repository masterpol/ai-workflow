# Appetite-auditor findings: state-project-sources

**Declared appetite:** big-batch — ≤15 files / ≤1500 LOC (`.project/pitches/state-project-sources/pitch.md:3`).

**Projected scope:** ~13–14 files / ~1600–1700 LOC with tests. The file count is within the 15-file cap but leaves almost no headroom; the LOC estimate exceeds the 1500 cap by about 7–13 % (1.07–1.13×), so this is a borderline big-batch. The pitch already names the right cut line; the recommendation is to accept it before betting.

## Bottom line

The pitch is borderline for big-batch because the LOC estimate already exceeds the cap. The biggest driver is the new SQL DDL reader, followed by workspace detection and source selection. The proposed cut (defer the route map) is the right one; accepting it should bring the pitch back under ~1500 LOC. Do not add Prisma, TypeScript schema parsing, or additional framework route maps without a scope raise or decomposition.
