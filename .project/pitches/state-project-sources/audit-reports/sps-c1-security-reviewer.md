- **Model:** Claude Sonnet 5.5 (`claude-sonnet-5-5`), dispatched worker.
- **Checklist:** I walked `ai-framework/rules/security.md` section 9 and the seven named patterns item by item. Results are in the checklist table below.
- **Cross-file interactions:** Reviewed. I traced `facts-gather.read` and `clean` into `facts-project` (reader, `stat`, `scrubPath`, `scrubLabel`) and `facts-sql.readSql`. I also traced `database()` and `structure()` through `projectPanels` and `explainer()`, including `sources` and `--json` output.

## Checklist results (section 9 and the named patterns)

| Item | Result |
|------|--------|
| One guarded reader | **Pass** for file reads. `helpers.read` refuses symlinks at any segment, non-regular files, realpath escapes and oversize files. `stat()` in `facts-project` also checks every segment. **Fail** for the byte bound across a directory (SEC-4). |
| Bound before regex, again after growth | **Pass** for `scrubPath`, `scrubLabel` and `clean`. They slice (4096 or 1024) before NFKC, and the regexes are bounded. I found no regex backtracking in `facts-sql`. The pnpm line regexes are linear. **Fail** for the non-regex quadratic in `render` (SEC-3). |
| Execute only bundle code | **Pass.** `grep` found no `import()`, `require`, `eval`, `Function` or child process in `facts-sql.mts` or `facts-project.mts`. The `drizzle.config.*` and `schema.ts` files are detected by name only. |
| Parse and re-emit untrusted values | **Partial.** The draft re-emits through `label`/`clean`/`fit`. The facts JSON and `sources` do not (SEC-1, SEC-8, SEC-9). |
| Never copy error text; atomic write | **Pass.** Catches return fixed strings. The one exception is the file name in the note (SEC-1). The writer is unchanged by this pitch. |
| Never let "absent" stand for "refused" | **Fail in one case** (SEC-6). Refused symlinks and unreadable directories do set `incomplete` or `unavailable`. |
| Resolve config from a trusted root | **Pass.** No project config is read. Workspace and Drizzle files are data only. |
| `a-report-over-an-untrusted-tree-runs-only-bundle-code` | Pass (see "Execute only bundle code"). |
| `backtracking-regex-over-untrusted-text-is-quadratic` | Regexes pass. A string-building quadratic exists (SEC-3). Lexer probes: unterminated quote, comment, dollar quote, `[` and many unterminated quotes at 1 MB each took 0-9 ms. 20 000 dollar tags took 0 ms. 1.9M nested parens took 0 ms (budget). |
| `counting-untrusted-labels-in-a-plain-object-inherits-prototype-keys` | **Pass.** Table, column, vote and count stores are `Map`/`Set`. Drizzle keys are read with `Object.hasOwn`. Probes `"__proto__"`, `constructor` and `toString` as table and column names (SQL and a Drizzle snapshot) gave correct entities, with no pollution and no crash. |
| `snapshot-metadata-bypassed-output-scrubbing` | **Fail** (SEC-1, SEC-8). |
| `allow-list-untrusted-labels-at-ingest-and-at-render` | **Partial.** Render side passes. Ingest does not allow-list SQL names (SEC-2, SEC-8, SEC-9). |
| `parse-untrusted-values-and-re-emit-them` | **Pass** for the ERD and tree panels (ids are generated). **Fail** for evidence and sources (SEC-1). |
| `a-source-scanner-fails-closed-on-what-it-cannot-read` | **Mostly pass.** Budget hits, symlinks, FIFOs and unreadable files give `stale` or `unavailable`, never `unconfigured`. Exception: SEC-6. |

## Tried, did not work (no finding)

- SQL with unterminated quotes, comments and dollar quotes, 1.9M nested parentheses, a 2 MB single statement and `[` loops: all linear (0-260 ms). The memory of a 1.8 MB comma-heavy statement was 452 MB RSS delta, which I count as acceptable.
- 5000-statement limit: 20 000 `CREATE TABLE`s stopped at 5000 with `incomplete: budget`.
- Ancestor, leaf and sibling symlinks and a FIFO: no read outside the project. No file content leaked into the output.
- Workspace literals with `..`, absolute paths and backslashes: refused by `stat()`. Odd YAML (comments, quotes, `!`, braces) is parsed linearly, with unresolved counting.
- Credential-named standalone directories (`secret`): refused as intended (the refusal makes the source `stale`; that is a minor availability cost, not a finding).
- Not probed (unverified): Archify's own rendering of `sources[].title` (SEC-1 is judged on the contract, not on a rendered exploit). The 8-file cumulative cost in SEC-3. A 1M-entry workspace directory. The two known doctor-test failures (excluded by the brief).
