`state-report.md`, the `/state` and `/bundle-sync` SKILL.md files. Checklist: `security.md` section 9 / checklist G, plus the three patterns.

## Checked, nothing found

- **Hostile names reaching Archify.** Project dir names, table names, column names, types, script names, and the project folder name were put through `label()` and then a real `archify validate`. Test project p1 used `@erd = x & $y`, `a|b`, a name with a newline, `AKIAABCDEFGHIJKLMNOP`, `sk_live_abcdefghijklmnopqrst`, `password=hunter2hunter2`, `ghp_...`, a script named `deploy --token=abcdefghijk`, `__proto__` and `constructor` table keys, a type `varchar(255) | @x`. Output text: `(at)t1`, `(at)erd : x + ¤y`, `a¦b`, `line break`, `(redacted)` for every credential shape, `deploy (redacted)`, `(at)a:b`. `validate` returned `ok: true` once the self-FK (row 3) was removed. Prototype keys were counted through `Map`s; no inherited key appeared as an entity.
- **Order of NFKC, redaction and directive neutralisation.** `clean()` runs NFKC before redaction, and `label()` replaces `@ = & $` after `clean()`, so full-width look-alikes (`＠`, `＝`) normalise first and are then neutralised. `fit()` truncates after `clean()`, so truncation cannot split a secret into a leaking fragment. `name()` slices at 1024 before `clean`, which could split a secret only across that boundary and leaves a tail without its keyword prefix.
- **Generated ids.** ERD ids `e1..`, relationship ids `r1..`, tree ids `d1..` are positional; no id is built from a project string. `references` is `<generated id>.<label with dots replaced>`. A 180-character folder name passed `validate` (project p4), so the unfitted root label is not rejected.
- **Credential shapes through project depth.** Same `clean()` path as other facts; stack never prints script bodies or dependency names (frameworks come from a fixed allow-list).
- **No project code, no child process.** `facts-project.mts` imports only `RuntimeDeps` types; test `all readers avoid process, network and database APIs` passes. `bundle-sync` reset test fixture uses a throwing `child`/`net` proxy. `archifyPinStep` reads bundle docs, anchors a 40-hex pin, never executes it, and only prints a fixed command with the hex.
- **Bounded reads in facts-project.** `json()` goes through `read()` (lstat per segment, realpath inside root, size bound 1 MB, then `text.length` recheck). Snapshot and `package.json` loops are bounded by the 1 MB source plus the entity/field/relationship budgets (`limit()` clamps NaN, negatives and floats). `stat()` lstat-checks every segment and refuses `.`, `..` and backslash components. Symlinked `drizzle/meta`, symlinked entries and non-directory path components all fail closed with fixed text.
- **Fixed error text.** The `safe()` wrapper returns a constant note; no `error.message` or absolute path reaches output in `facts-project.mts`, `resetStateReports` hints (fixed reason codes only), or `report-not-owned: <validated name>`.
- **bundle-sync reset, symlinks and FIFOs.** `assertNoSymlinkPath(reports)` covers `.project` and `reports`; `readBounded` does `lstat` regular-file check, `O_NOFOLLOW|O_NONBLOCK` open, `fstat` identity (dev/ino) and a bounded read of limit+1; legacy pages are only listed; preflight of every target happens before the first removal, and a kept target keeps the receipt. A receipt that names a hash can only ever make the three fixed names removable.
- **Symlinked destination.** `ln -s /etc/hosts .project/reports/state.explainer.json` then `--explainer`: `facts-gather: Symlink destination forbidden`; `/etc/hosts` untouched.
- **Receipt as trust anchor.** A hostile project can plant a receipt, but that only lets the tool replace or delete a file whose bytes already match a hash the attacker chose from a fixed generated name, which they already control.
- **workflow-doctor.mts one line.** Adds two file names to the kept-complete list only.
- **State-report.md and both SKILL.md edits.** Documentation matches the code (the single `.project/reports` deletion exception is stated, the playbook tells the agent not to delete or overwrite a file it does not own). No instruction to run project-supplied code.

## Unverified

- **Directory-swap race in `facts-project` listings.** `stat()` lstat-checks `drizzle/meta` and each walked directory, then `readdirSync(path)` follows the path. Swapping a verified directory for a symlink in between would list names outside the project (names only, then cleaned). Not reproduced; same class as the documented rename window.
- **`assertNoSymlinkPath` now lstat-checks its `base`** (`bundle-sync.mts:262`) for every existing caller, not only the new reset. If a project root or `--source` path is reached through a symlink, all sync writes and `archifyPinStep` now refuse or return `[]` silently. Not run end to end; `process.cwd()` is normally already a realpath, so this is probably benign.
- **Archify's own HTML escaping of facts-block text and the viewer.** I validated the draft, not the rendered `state.html`; I did not run `deliver`, because it writes into the target and the receipt format was out of scope. I also did not inspect the rendered DOM for the `¦`, `‹`, `¤` look-alikes.
- **Large-listing memory.** `readdirSync` loading a whole huge directory is the documented residual; not measured.
- **Entity-name collisions.** Two tables with the same cleaned or raw name make `index` keep the first, so a foreign key can bind to the wrong table. Integrity of the diagram, not a security boundary; not tested through `validate`.
- **Structure names as disclosure.** Directory names such as `secrets` or `credentials` are listed as labels (names only, never contents). The multipage pattern asks for one shared secret-name policy; whether that applies to a label listing is a policy call I did not settle.
