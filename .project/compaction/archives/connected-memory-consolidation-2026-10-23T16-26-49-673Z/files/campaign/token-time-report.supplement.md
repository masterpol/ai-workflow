## Design decisions

- Pure joiner owns typed projections and joins; renderer consumes its sanitized model; CLI imports inward and uses RuntimeDeps. No reverse CLI/filesystem dependency in the pure module.
- Read token schema 3 and usage schema 2 under one guarded metrics lease; release before rendering/publication. Never call a writing transaction to read. Preview creates no files/directories, including when metrics is absent. Usage v1 compatibility is in memory only and remains legacy/unjoinable.
- Exact components: pitch matches ^[a-z0-9][a-z0-9-]{0,79}$, phase is one of the resolver's 12 phases, scope S plus 1–3 digits or (none). No live-folder check or historical identity re-resolution. (other), (unknown), (unattributed) and noncanonical legacy rows remain source-specific. Preserve one-sided rows and each source's overflow totals.
- Validate unknown disk values, dates, safe nonnegative counts, reporting consistency and reserved keys. All label maps use Map/null-prototype storage. Scrub credential-shaped labels and metadata in JSON as well as Markdown/HTML; fixed reasons never echo rejected values.
- Token leaves roll up once with checked arithmetic. No reported usage gives null; partial reporting shows known sums plus coverage. Timing copies stored union rows, never sums overlapping children or vendor copies. Pending/buffered intervals make timing provisional; no extrapolation. Wait is between-turn elapsed lower bound, not necessarily think time. Sources older than seven days are stale.
- Optional schema-1 state.json history is separately guarded under pinned project/reports ancestry, outside the metrics lease. Validate enclosing/nested Fact availability, generatedAt, exact slugs, revisions and truncation. Missing slug in truncated history is unavailable, never zero or proof of not-shipped.
- Each source/history input and each format is bounded to 4 MiB. Token caps: 51 pitch buckets, 16 phases, 26 scopes, 600 vendor leaves. Usage retains its reader's overflow-inclusive 52 pitch/18 phase limits; applying token caps to usage was corrected in S1. History at most 200 items, trace at most 32. Output keeps 100 leaf rows and displayed ancestors in stable lexical order, with omitted counts and separate full/displayed totals. Over-limit source/output refuses rather than truncating silently.
- Exclusive private staging and wx files, pinned ancestors/stage identities checked per operation, staged-byte rechecks, format-specific ownership markers, target reinspection, exclusive link for new files and verified rename for existing ones. Cleanup owns only identified attempt files and records publication before fallible cleanup.
- Static multi-table HTML uses captions, semantic headers, keyboard-focusable internal scroll regions, viewport, CSP, no scripts/external resources, neutral UA light/dark styling. Shared table model keeps formats aligned. Generic application progressive-disclosure/branding rubrics were excepted for this internal document; browser geometry/contrast were never measured.
