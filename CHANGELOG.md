## [2.1.0] - 2026-09-23
### Changed
- bundle-sync protects project customizations with a three-way comparison
- Each differing file is compared against the bundle version last synced from (hash manifest in .project/.bundle-sync.json, or --base-ref <git ref> on a first sync): upstream-only changes apply, project-only edits are kept, edits on both sides are reported as conflicts and never overwritten
- Handles case-only renames (skill.md -> SKILL.md) on case-insensitive filesystems; --prune deletes upstream-removed files only when unmodified; scans retired directories (ai-framework/contexts) so their removal is reported
- setup-validator no longer treats <placeholders> inside inline code or code blocks as an unfilled setup draft, so stack.md can map workflow command placeholders
- Found while syncing the LAH project: a plain overwrite would have silently discarded its testing-rule addition and its project-specific /ship verify gate
